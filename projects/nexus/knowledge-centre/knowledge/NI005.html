NI005 · Network Intelligence

NI005

```text Do two or more entities share the same address? ``` Supporting questions: ```text How many entities use the address? Is the address residential or commercial? Is the address associated with high-risk entities? Does the address appear in multiple ownership structures? Does the address indicate a shell company network? Does the address create additional risk? ``` ---

NI005 Common Address identifies entities connected through a shared address. The purpose of this intelligence product is to detect relationships that may indicate: - Undisclosed connections - Common control - Related-party activity - Shell company networks - Network clustering - Beneficial ownership concealment - Financial crime exposure While a shared address alone is not suspicious, it may become highly significant when combined with ownership, control, trade or sanctions indicators. ---

Risk indicators

Risk

  • Twenty entities registered at same address
  • Address linked to shell companies
  • Address linked to sanctioned entity
  • Address appears across multiple ownership networks
  • High-risk address cluster detected

Investigation actions

  1. Common Registered Addresses
  2. Common Residential Addresses
  3. Common Operational Addresses
  4. Shared Mailing Addresses
  5. Large Address Clusters
  6. Address Reuse Across Networks

Detection logic

NI005 should identify: ```text Common Registered Addresses Common Residential Addresses Common Operational Addresses Shared Mailing Addresses Large Address Clusters Address Reuse Across Networks ``` ---
