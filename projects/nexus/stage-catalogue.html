The rollout gate — five-layer functional test

Every typology is shippable only when it passes this chain, positive and negative, on full data — the false-positive guards matter as much as the detections.

LayerProvesPositiveNegative — false-positive guard
L0 · NetworkER & control chains resolve and feed the typologythe same-interest link resolves (controller → both ends)unrelated entities don't falsely merge
L1 · Analyticthe detector finds the patternpattern present → detectedclean fixture → not detected
L2 · Scorecomponents → correct score + bandpinned score; each contribution correctbelow-threshold clean → Low
L3 · Alertfires / escalates / suppresses rightfires; a sanctions match escalates to Criticalclean → no alert; tuned-out → suppressed
L4 · Outputthe intelligence products are correctwalk + SAR + case built, provenance-linkedno output when there is no alert

Engineering posture

DeterministicEvery rendered page and dataset is byte-identical to rebuild — no hidden randomness, no timestamps in output.
Governed baselineA single baseline count gates the estate; every merge re-pins it and the full suite stays green.
ReviewedEach sub-project passes a whole-branch review before merge — spec compliance and code quality both.
