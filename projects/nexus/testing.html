Test Phase

Testing before the next features.

From 19 October 2026 new features are frozen for about twelve weeks, to about 11 January 2027, while the platform is tested against a written strategy in six phases. Only defect fixes and test work land. Agents run test packages every night against a fixed baseline, every new test is seen to fail before it is trusted, and the expected outcomes for the realistic test estate are written from the typology doctrine, never from the code. For what the platform does, see mission status.

How it is tested

Seen to failA guard is trusted only after it has gone red on the fault it guards, and green again once restored.
Oracle from doctrineExpected outcomes are written from each typology's doctrine and signed off typology by typology, never read back from the code.
Baseline-gatedEvery landing holds a pinned CI baseline, measured on a clean clone, with zero failures.
No moving outputsA fix may change what a page says. It may not move a score, band or rank unless that is the defect.
