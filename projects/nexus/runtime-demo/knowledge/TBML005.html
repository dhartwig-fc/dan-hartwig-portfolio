TBML005 · TBML

False Description Of Goods

Do the goods as declared match the goods that actually ship — or is a false description being used to conceal the true commodity, its value, or its control status?

False Description of Goods declares a consignment as something other than what actually ships — a different commodity, HS code, quality or control status. The misdescription lets the trader misstate value, conceal a controlled or high-value item, evade duty, or move value under cover of an innocuous commodity.

It is used to:

  • Understate or overstate value by mislabelling the commodity
  • Conceal controlled, dual-use or sanctioned goods behind a benign description
  • Evade tariffs and quotas
  • Move value under the appearance of ordinary trade
  • Support related-party value transfer

Risk narrative

A customer imports a consignment declared as one commodity, but inspection shows the goods are something else — often in a different HS chapter, of materially different value, or subject to control. The paperwork is internally consistent with the declared commodity; only a reconciliation against the inspected goods reveals the misdescription. Where the counterparty is a shell and the parties share ownership, the false description is a transfer or concealment mechanism rather than a clerical error.

Risk indicators

Risk

  • Commodity Mismatch
  • HS Chapter Mismatch
  • Controlled-Goods Concealment
  • High Value Trade
  • Related Party Trading
  • Shell Company Structure

Investigation actions

  1. Inspect the goods; confirm the actual commodity, HS code and value.
  2. Reconcile the declared description against the inspection.
  3. Assess the value and control status of the true goods.
  4. Resolve ownership; test for shared directors / owners and related-party trade.
  5. Package evidence for investigator review where the score is High or above.

Use cases

  • Trade Based Money Laundering (TBML)
  • Duty / Tariff Evasion
  • Dual-Use / Controlled-Goods Concealment
  • Related Party Value Transfer
  • Shell Company Abuse
  • Sanctions Evasion
